# 風格庫

本 fork 保留上游 `references/` 風格庫。

Windows v4 建置器會把 copied skill 中的 Markdown reference 轉成繁體中文，並同步轉換檔名；不修改原始 `skills/codex-ppt`。

## 使用原則

AGY 可以：

- 選擇內建風格
- 讀取個人風格庫
- 根據使用者參考圖建立新的 style note
- 維持整份簡報的共同 visual identity

Codex 只執行 AGY 指定的風格，不自行選風格。

## 個人風格庫

如果仍沿用上游個人 reference home，應保持在 Skill 安裝目錄之外，避免更新 fork 時被覆蓋。
