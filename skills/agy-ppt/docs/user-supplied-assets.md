# 使用者提供素材

使用者指定的圖片、圖表、截圖、logo、論文圖、產品照片等，都視為 strict input asset。

## AGY 負責

- 確認 asset 對應哪一頁
- 記錄 asset 的用途
- 定義不可改動的 invariants
- 把 asset path 寫入 slide job
- 最終檢查是否真的被保留

## Codex 負責

- 在指定頁使用素材
- 保留 identity / logo / 重要圖表內容
- 不自行替換成「類似素材」

## 禁止

- 找另一張網路圖片代替使用者原圖
- 因為版面不好排就刪掉 required asset
- 未經要求修改 logo、文字、產品內容或資料
