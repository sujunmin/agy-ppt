# Public examples

These examples show two distinct presentation styles: a dense, card-rich
executive story and a more balanced briefing. They use synthetic cases and
data. Their PNGs are rendered from the resulting PowerPoint decks; the source
decks are not qualification bundles or product benchmarks.

| Example | Profile | Preview |
| --- | --- | --- |
| [Dense Executive](dense-executive/README.md) | Dense, information-rich, image-rich | ![Dense Executive, slide 1](dense-executive/previews/slide-1.png) |
| [Balanced Executive](balanced-executive/README.md) | Balanced, moderate cards and imagery | ![Balanced Executive, slide 1](balanced-executive/previews/slide-1.png) |

Each folder contains a reproducible prompt, approved outline, style profile,
public-safe image assets, and four actual-output slide previews. To recreate a
deck, load the repository skill in AGY, provide the prompt and outline, choose
the listed profile, and complete the normal outline, style, and sample review
steps. Figures and organizations in these examples are fictional.

The examples are public-facing demonstrations. Engineering regression and
qualification materials belong in benchmarks or external qualification
storage, not here.

## Contribute an example

Pull requests that improve layout grammar, presentation styles, charts,
typography, image treatments, accessibility, PowerPoint compatibility, or add
another reproducible example are welcome. For visual changes, include the
reproducible prompt/input, before/after renders, a generated PPTX where
practical, the environment/client used, and relevant tests. Large binaries do
not need to be committed unless they are intentional fixtures.
